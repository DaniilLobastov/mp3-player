# MP3 Player на Python

![Python](https://img.shields.io/badge/Python-3.6+-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)
![GUI](https://img.shields.io/badge/GUI-Tkinter-orange.svg)

Простой, но функциональный MP3-плеер с графическим интерфейсом, написанный на Python. Идеальный учебный проект для начинающих!

## 🎵 Возможности

- **📁 Загрузка музыки** - выбор папки с MP3-файлами
- **🎶 Управление воспроизведением** - Play, Pause
- **⏭️ Навигация** - переход к предыдущей/следующей композиции
- **📊 Визуализация** - прогресс-бар с отображением текущей позиции
- **🔊 Контроль громкости** - регулировка уровня звука
